# 快速开始 / Quick start

## 打开文档 / Open a document

- `⌘O`（菜单里记为 `Ctrl + O`）打开文件；也可以把 PDF 拖到窗口或 Dock 图标上。
- 支持 PDF、EPUB、MOBI、FB2、CHM、XPS、DjVu、CBZ/CBR、图片等常见格式。
- 从 Finder 双击打开、或拖到 Dock 图标上，通过 Apple Event 传递，程序会排队到第一个窗口就绪后打开。

Use `⌘O`, drag a file onto the window or Dock icon, or double-click it in Finder. Files arriving as
Finder Apple Events are queued until the first window is ready.

## 标签页 / Tabs

设置里启用「使用标签页 / Use tabs」后，一个窗口内可以开多个文档。
`⌘Tab` / `⌘⇧Tab` 在标签间切换，`⌘W` 关闭当前文档。

Enable "Use tabs" in Settings to keep several documents in one window.

## 阅读与导航 / Reading and navigation

- 滚动：`j` / `k` / `h` / `l` 或方向键；`Space` 翻到下一页，`⇧Space` 回到上一页。
- `n` / `p` 下一页 / 上一页；`Home` / `End` 首末页；`⌘G` 跳转到指定页。
- `⌘F` 查找，`F3` / `⇧F3` 下一个 / 上一个匹配。
- `⌘0` 适合整页、`⌘1` 实际大小、`⌘2` 适合宽度、`⌘3` 适合内容。
- `F11` 全屏，`F5` 演示模式；`F12` 显示/隐藏书签。

## 视图与主题 / Layout and theme

`⌘6` 单页、`⌘7` 双页、`⌘8` 书籍视图；`c` 切换连续滚动，`z` 切换缩放。
主题（Theme）选择 `System` 时，界面跟随 macOS 深色/浅色外观。

Choose the `System` theme to follow the macOS light/dark appearance.

## 语言 / Language

在 `Settings → Change Language` 里只有 `English` 与 `简体中文` 两项。中文系统首次启动会自动选中文。
切换后菜单与对话框立即刷新；设置保存在
`~/Library/Application Support/SumatraReader/SumatraReader-settings.txt` 的 `UiLanguage`。

Only `English` and `简体中文` are offered. A Chinese macOS defaults to Chinese on first launch.

按 `F1` 打开、再按一次关闭；也可用 `帮助 → 使用手册`。手册从程序内嵌资源读取，无需联网。
Full-text search is available in the manual's own search box.

更多内容见 [快捷键](Keyboard-shortcuts.md)、[macOS 集成](macOS-notes.md) 和 [常见问题](Troubleshooting.md)。
